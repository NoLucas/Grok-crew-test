# 다운로드 둘로 나누기 — 실행 계획표

합의: 사람은 Windows 책상 파일을 받고, 봇은 설치 마법사가 아닌 전용 zip을 받는다. 다운로드 첫 질문은 관리자가 아니다. 관리자를 거부하면 PDF만 주지 않고, 관리자 없이 실행되는 파일을 같이 준다. Mac·서명·공증·Instagram 앱은 이 표에 넣지 않는다.

날짜나 주 단위 일정은 적지 않는다. 순서와 완료 조건만 적는다. 짧은 기본을 코드로 만드는 순서는 `docs/SIMPLE_PATH.ko.md`다.

**상태 (2026-08-26):** 0판 문장과 1판 NSIS 설정은 SIMPLE_PATH E/F로 코드에 들어 있다. 아래 옛 체크박스는 초안이다. 2판 이후(모든 계정 exe, 압축 zip, PDF)는 아직 예비다. 이 Linux 기계에서 exe를 만들지 않는다.

## 더 줄인 기본 (사람이 걷는 길)

위 둘 나누기는 **뒤에 숨긴 준비물**이다. 사람이 걷는 기본은 더 짧다.

지금 표만 따르면 고르는 일이 많다. 받을 파일, 설치/압축, 봇 zip, PDF, 수집/편집, 받기 버튼. 비전공자 기본은 아래 네 번만이다.

1. **받는다** — 사이트 버튼 하나. `GrokCrew-Windows.exe`
2. **연다** — 더블클릭. 마법사 다음 다음이 없다. 계정 폴더에 바로 들어간다.
3. **적는다** — 제목 한 줄. 스타일은 인스타 릴이 이미 골라져 있다. 파일을 끌어다 놓으면 내 영상이다.
4. **붙인다** — **봇에게 이 말 복사**. 두 번째 다운로드 없음. 한 봇이 소스와 컷을 같이 한다.

컷이 오면 창이 그걸 연다. 받기 버튼 없음.

사이트에 봇 zip을 두지 않는다. PDF를 따로 받게 하지 않는다. 안 열리면 같은 페이지에 그림 세 장(보호 화면 → 추가 정보 → 그래도 실행)만 보여 준다. 봇 zip·모든 계정 exe·압축 zip·PDF는 “다른 방법” 아래에만 둔다.

창 기본도 봇 둘이 아니다. 이미 있는 한 문 규격(`waiting_for_bot`)이 기본이다. 수집 봇 + 편집 봇은 “역할 나누기”를 연 사람만 본다.

줄이지 못하는 것: 서명 없는 exe의 SmartScreen, 무엇을 만들지만은 적기, 이 컴퓨터(또는 폴더)에 봇이 있어야 한다는 것.

## 고정한 결정

| 결정 | 내용 |
|---|---|
| 사람용 기본 | 이 계정에만 설치. 비밀번호를 묻지 않음 |
| 사람용 선택 | 모든 계정에 설치. 비밀번호를 물을 수 있음. 작은 글씨 |
| 막혔을 때 | 계정용 파일 또는 압축 실행 + 그림 PDF |
| 봇용 | `GrokCrew-봇에게주기.zip`. exe 아님. 관리자 없음 |
| 사이트 버튼 | 크게 **내 컴퓨터에 설치**, 작게 **봇에게 줄 파일**, 막히면 **그림 설명서** |
| 책상 안 | 연 뒤에도 **봇에게 줄 파일 받기** |
| 봇 zip 역할 | 이미 켜진 책상에 체크인하는 글 + 스크립트. 두 번째 창을 띄우지 않음 |
| 뒤 폴더 | `handoff-outbox/editor`, `handoff-outbox/collector`. 예전 `grok/`·`agents/`는 읽기만. 사람에게 보여 주지 않음 |

## 사람이 보는 최종 경로

기본:

1. 사이트에서 **Windows에서 열기** 하나.
2. 더블클릭. 설치 마법사 없음.
3. 제목을 적거나 파일을 놓는다.
4. **봇에게 이 말 복사**를 붙여 넣는다. 한 봇이다.
5. 컷이 오면 열린다.

`git`, `npm`, Python, 포트, purpose, 문, 두 번째 다운로드, 받기 버튼은 이 경로에 없다.

뒤에 숨긴 준비물: 봇 zip, 모든 계정 exe, 압축 실행, PDF. 기본이 막힐 때만 꺼낸다.

## 결과물 이름

릴리스에 올리는 파일 이름은 한글로 읽히게 고정한다. 빌드 산출물이 영어여도 공개 이름은 아래로 맞춘다.

| 공개 이름 | 실제 내용 | 누가 받나 |
|---|---|---|
| `GrokCrew-Windows.exe` | 계정용 NSIS. 기본 | 사람 |
| `GrokCrew-Windows-모든계정.exe` | 기계 전체 NSIS. 선택 | 사람, 작은 글씨 |
| `GrokCrew-Windows-압축실행.zip` | 풀고 `Grok Crew.exe` 실행. 설치 거부용 | 사람, 막혔을 때 |
| `GrokCrew-봇에게주기.zip` | 봇이 읽는 묶음 | 사람 → 봇 |
| `GrokCrew-설치설명서.pdf` | 그림 4~6장 | 막혔을 때 |

한 페이지에 다섯 개를 나란히 두지 않는다. 기본 노출은 exe 하나다. 안 열리면 같은 페이지 그림 세 장. 봇 zip·PDF·다른 exe는 “다른 방법”이다.

## 1판 — 사람용 Windows, 계정 설치가 기본

지금 `package.json`의 NSIS는 폴더를 고를 수 있고, 계정/전체 구분이 없다. 기본을 계정 설치로 못 박는다.

할 일:

- [x] electron-builder `nsis`를 계정 설치로 둔다. `perMachine: false`. 기본은 비밀번호를 올리지 않는다. 기본 경로는 마법사 페이지가 없다(`oneClick` 또는 받아서 바로 실행). (SIMPLE_PATH F)
- [x] 산출물 파일명을 `GrokCrew-Windows.exe`로 고정하는 설정을 넣는다.
- [ ] 설치 경로 기본은 사용자 폴더다. Program Files가 기본이 아니다.
- [ ] `npm run desktop:dist`가 이 exe를 `release/`에 남기는지 확인한다.
- [ ] 설치 후 더블클릭하면 책상 창과 Local Studio 사이드카가 같이 뜬다. 지금 sidecar 묶음(`extraResources`)을 유지한다.
- [ ] 첫 실행에서 Node/Python을 묻지 않는지 확인한다.

완료 조건:

- 관리자 비밀번호 없이 계정에 설치되고 창이 열린다.
- 사이드카가 없으면 책상이 로컬 서비스 오류만 보여 주고, 설치를 다시 시키지 않는다.

건드리는 곳: `package.json` `build.nsis` / `build.win`, 필요하면 `scripts/` 한 파일. 서명·`notarize`는 건드리지 않는다.

위험: 서명되지 않은 exe는 SmartScreen이 막는다. 1판에서 서명을 넣지 않는다. 5판 PDF가 그 화면을 설명한다.

## 3판 — 봇에게 줄 zip

봇 파일은 두 번째 설치가 아니다. 책상이 이미 켜져 있어야 한다.

zip 안:

```
GrokCrew-봇에게주기/
  지금_이렇게_하세요.txt
  grok_crew.py
```

`지금_이렇게_하세요.txt`에만 적을 것:

- 책상 창이 이미 열려 있어야 한다.
- 아래를 이 컴퓨터 봇에게 붙여 넣는다.
- 수집이면 `--purpose collect`, 편집이면 `--purpose edit_video`.
- `--display-name`은 봇 자기 이름.
- 다른 주소로 연결하지 말 것.
- 관리자 실행 없음. 설치 없음.

할 일:

- [ ] `scripts/pack-bot-bundle.mjs`(또는 py)가 위 zip을 만든다. CLI는 지금 `GET /downloads/grok-crew.py`가 주는 그 파일이다.
- [ ] 한글 안내 원문은 `docs/bot-pack/지금_이렇게_하세요.txt`에 두고 스크립트가 복사한다.
- [ ] `npm run dist:bot-pack`으로 zip이 `release/GrokCrew-봇에게주기.zip`에 생긴다.
- [ ] zip 안에 studio 서버, Electron, sidecar, `.env`, 토큰을 넣지 않는다.
- [ ] 같은 PC가 아닌 봇에게는 “이 zip은 이 컴퓨터 봇용이다” 한 줄을 적는다. 원격 폴더 인계는 이 판에 넣지 않는다.

완료 조건:

- zip을 받은 봇이 `entry` 한 줄로 책상에 이름이 뜬다.
- zip을 더블클릭해도 설치 마법사가 나오지 않는다.

건드리는 곳: `scripts/pack-bot-bundle.*`, `docs/bot-pack/`, `package.json` 스크립트. 책상 UI는 4판.

완료 조건:

건드리는 곳: `app/desktop-spec-desk.tsx` 또는 첫 화면, `desktop/` 저장 대화상자, `local_studio/handlers.py` 다운로드 경로, 테스트 한 개.

## 5판 — 그림 설치 설명서 PDF

관리자 거절·SmartScreen용이다. 설치를 대신하지 않는다.

페이지(4~6장, 한국어 먼저):

1. **받을 버튼** — “내 컴퓨터에 설치”를 누른 화면.
2. **파일 찾기** — 다운로드 폴더의 `GrokCrew-Windows.exe`.
3. **파란 보호 화면** — “Windows의 PC 보호” → 추가 정보 → 그래도 실행. 관리자가 아니라고 적는다.
4. **창이 열림** — 샘플 보기.
5. **봇 파일** — 책상의 “봇에게 줄 파일 받기” 또는 사이트의 작은 버튼.
6. **그래도 안 되면** — 압축 실행 zip을 풀어 `Grok Crew.exe`를 연다.

할 일:

- [ ] 원본 슬라이드/페이지는 `docs/install-guide/`에 둔다. 스크린샷은 실제 창이다.
- [ ] PDF를 `release/GrokCrew-설치설명서.pdf`로 보낸다. 앱에 PDF 엔진을 넣지 않는다.
- [ ] 사이트 “설치가 막히면”이 이 PDF를 연다.
- [ ] PDF에 `git`, 포트, purpose, Runner, Instagram을 넣지 않는다.

완료 조건:

- 컴퓨터에 익숙하지 않은 사람이 3장만 보고 SmartScreen을 지나간다.
- PDF만 받고 exe/zip이 없으면 경로가 성립하지 않는다고 릴리스 체크에 적혀 있다.

## 하지 않는 일 (이 표 전체)

- 다운로드 첫 질문에 관리자 예/아니오를 두는 일
- 봇용 NSIS/exe 설치 마법사
- 봇 zip에 sidecar·토큰·`.env`를 넣는 일
- 이 저장소에서 Instagram/TikTok/YouTube 앱을 만들거나 `notarize: true`로 바꾸는 일
- Mac DMG를 이 표의 기본 산출물에 넣는 일
- 원격 git 인계를 봇 zip 기본 경로에 넣는 일
- Local Studio를 인터넷에 여는 일
- 문 폴더 이름 `grok/` · `agents/`를 바꾸는 일

## 한 줄로 보는 순서

```
0 입구 문장
 → 1 계정용 Windows exe
 → 2 모든계정 exe + 압축 실행 zip
 → 3 봇 zip
 → 4 책상에서 봇 zip 받기
 → 5 그림 PDF
 → 6 릴리스에 올리기
```

## 의존과 위험

- **사이드카 묶음:** 사람 exe가 이미 `build/sidecar`를 넣는다. 1판에서 이 경로를 빼면 창만 뜨고 저장이 죽는다.
- **미서명:** SmartScreen은 1판부터 있다. 5판 전에도 exe를 올릴 수는 있으나, 설명서 없이 올리면 비전공자는 여전히 막힌다.
- **봇 zip과 7214:** 봇은 책장이 켠 루프백만 쓴다. zip이 서버를 또 켜면 포트가 겹친다.
- **이름:** 체크인 `display_name`과 purpose로 자리가 갈린다. 봇 zip 안내가 purpose를 빼먹으면 둘 다 편집으로 붙을 수 있다.
- **Windows만:** Mac은 별 표. 이 표를 확장할 때 DMG를 세 번째 사람 파일로 더한다.
